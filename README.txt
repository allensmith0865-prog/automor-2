HOW TO UPLOAD TO HOSTINGER (5 steps)
------------------------------------------------------

STEP 1 — Login to Hostinger
  Go to hpanel.hostinger.com and log in.

STEP 2 — Open File Manager
  My Hosting → Manage → File Manager

STEP 3 — Go to public_html
  Click the "public_html" folder.
  Delete any existing files inside it (default pages).

STEP 4 — Upload files
  Click Upload → select ALL files from this zip:
    ✓ index.html
    ✓ .htaccess
  (Make sure .htaccess is included — it may be hidden)

STEP 5 — Done!
  Visit your domain. Your website is live.
